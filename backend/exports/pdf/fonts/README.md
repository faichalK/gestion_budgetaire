# Polices IBM Plex

Placez ici les fichiers TTF téléchargeables sur https://github.com/IBM/plex/releases

Fichiers requis :
- IBMPlexSans-Regular.ttf
- IBMPlexSans-Medium.ttf
- IBMPlexSans-Bold.ttf
- IBMPlexMono-Regular.ttf
- IBMPlexMono-Bold.ttf

Sans ces fichiers, le module utilise automatiquement Helvetica/Courier (intégrés à ReportLab).
